# Data

This folder contains compact inputs and intermediate analysis datasets retained for
documentation of the ENSO climate-exposure module.

- `registry/`: mine registry, thresholds, and channel definitions
- `panels/`: mine-month / mine-year analysis panels
- `ledger/`: master stress ledger and panel-version metadata
- `inputs/`: selected source inputs required by downstream scripts

Large raw climate files used in the earliest ingest stages are not redistributed.
