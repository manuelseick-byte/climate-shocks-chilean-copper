# Methodology note

The adaptation proxy is based on desalination/seawater infrastructure commissioning
rather than observed mine-level water consumption.

This distinction matters for identification. Adapted mines differ systematically from
non-adapted mines and some commissioning dates coincide with broader investment projects.
The interaction regressions are therefore treated as diagnostic rather than causal.

The module supplements them with within-mine event timing, switcher-focused samples,
leave-one-out diagnostics, channel placebos, and wild-cluster-bootstrap inference.

The cumulative drought specification is aligned with the main ENSO climate-exposure
module.
