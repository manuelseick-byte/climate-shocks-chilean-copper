# Data

## `financials/`

Contains the mine / operator financial dataset used for the cost-side screening.

## `event_coding/`

Contains:

- the annual-report review worklist;
- the manually coded event ledger; and
- the desalination/adaptation registry used for cross-referencing commissioning events.

The underlying annual reports and financial statements are not redistributed. Source and
page references are recorded in the worklist.
