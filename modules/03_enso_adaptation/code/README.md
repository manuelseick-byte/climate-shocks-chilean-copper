# Code

The scripts are ordered by workflow:

1. `00_translate_decrees.py` — translates the DGA registry for documentation.
2. `01_build_decree_panel.py` — constructs the derived decree / ENSO inputs.
3. `02_make_figures.py` — generates the public-facing figures.
4. `03_reproduce_decrees.py` — reproduces the reported statistics and verification block.

Only repository-relative path handling has been changed for public organisation.
