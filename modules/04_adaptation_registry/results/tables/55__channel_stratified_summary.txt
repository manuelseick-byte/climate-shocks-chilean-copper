 Interpretation framework:
   - PRIMARY  significant + positive => adaptation moderates drought (hypothesis confirmed)
   - PRIMARY  null or negative     => moderation hypothesis not supported in panel
                                       (event study remains the cleaner test)
   - PLACEBO  null                 => adapt is a clean water-source variable
   - PLACEBO  non-zero             => additional channel: coastal-logistics exposure
                                       created BY adaptation, not eliminated by it
   - INTERMED null or weak         => expected; desalination is not a heat-stress intervention
