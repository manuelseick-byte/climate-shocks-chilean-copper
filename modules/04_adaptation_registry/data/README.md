# Data

- `panels/` contains the mine-month and mine-year analysis panels and the adaptation
  coding summary.
- `registry/` contains the desalination/adaptation registry and channel definitions.
- `inputs/cochilco/` contains the monthly copper-production input used by the
  adaptation-panel construction script.

Large raw climate datasets are maintained in the separate ENSO climate-exposure module
and are not duplicated here.
