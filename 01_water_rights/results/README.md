# Results

This folder contains a selected set of final, public-facing outputs from the water-rights and governance module.

- `Water_Governance_Section.pdf` — final written section prepared for the Master Project workflow.
- `figures/` — selected maps and descriptive charts used to document water-governance constraints and adaptation patterns.

Large intermediate Excel workbooks, JSON payloads, draft Word reports, duplicate figures, and temporary files from the original working directory are intentionally omitted.
